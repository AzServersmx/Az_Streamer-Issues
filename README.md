# Az_Streamer-Issues
Soporte oficial, reportes de errores y sugerencias para Az_Streamer | AZ Servers 💙

¡Hey! Bienvenido al espacio de soporte de **Az_Streamer**, un plugin de Minecraft creado con mucho cariño por **AZ Servers**. 💙

Este repositorio está dedicado a escuchar a nuestra comunidad, resolver problemas y recibir nuevas ideas para mejorar el plugin.

## ¿En qué podemos ayudarte?

- 🐛 **Reportar errores:** ¿Encontraste algún problema? Cuéntanos qué ocurrió.
- 💡 **Sugerir funciones:** ¿Tienes alguna idea para mejorar Az_Streamer? ¡Nos encantaría conocerla!
- 💬 **Resolver dudas:** Puedes utilizar nuestro Discord para recibir ayuda.

## Antes de reportar un error

Por favor, incluye:

- Versión de Az_Streamer.
- Versión de Minecraft y Paper.
- Descripción del problema.
- Pasos para reproducirlo.
- Capturas o registros de consola, si los tienes.
